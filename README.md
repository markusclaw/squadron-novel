# Squadron — A Novel

This repository is the canonical source of truth for the **Squadron** novel: story outline, character bibles, world-building, lore, timeline, and manuscript.

## Repository Structure

```
squadron-novel/
├── README.md                    (this file)
├── OUTLINE.md                   (story structure, acts, chapters)
├── CHARACTERS.md                (character bibles, arcs, voice)
├── WORLDBUILDING.md             (setting, rules, history, factions)
├── TIMELINE.md                  (chronological events)
├── GLOSSARY.md                  (terminology, abbreviations, lore)
└── manuscript/
    ├── act-01/
    ├── act-02/
    ├── act-03/
    └── epilogue/
```

## How to Use This Repo

1. **Canon is locked here.** When in doubt about lore, character backstory, or timeline—check these docs.
2. **Manuscript lives in `manuscript/` as `.md` files.** One file per chapter or act section.
3. **Push changes** to keep the repo in sync with the latest draft.
4. **Branch for experimental content** if needed, then merge back when ready.
