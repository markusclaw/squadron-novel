## Canon Status System

Every significant fact belongs to one of four states:

- **● CANON** — Accepted and currently authoritative
- **◆ PROVISIONAL** — Preferred direction, subject to change
- **○ OPEN** — Intentionally undecided
- **✗ REJECTED** — Previously considered, explicitly abandoned

## Repository Principles

1. **Markdown is authoritative.** PDF, DOCX, EPUB, and website builds are outputs.
2. **Do not fabricate missing lore.** Mark gaps as OPEN.
3. **Source of truth rule.** GitHub repository is canonical. GitHub Pages is readable interface.
4. **Continuity protection.** Repository makes it difficult to contradict ourselves.

---

## Contributing / Updating Canon

For meaningful story changes:

1. Update relevant Markdown files
2. Update `CANON_LEDGER.md`
3. Append to `DECISIONS.md` (if architectural change)
4. Update `CHANGELOG.md`
5. Ensure dependent pages remain consistent
6. Commit with descriptive message: `story: [what changed]`
