# Relays

The communications network that keeps the squadron tied to Command and to one another.

## Established function <span class="sq-badge provisional">PROVISIONAL</span>

When the squadron loses **Relay** connectivity, [Kristina](../characters/kristina.md)
disappears from their communications. The Relay is therefore not just infrastructure —
losing it is losing a *voice*, which is how the story makes network failure emotionally
tangible.

## Open <span class="sq-badge open">OPEN</span>

Mechanics, range, how it fails, and its relationship to [The Lattice](lattice.md) are
undecided. Do not over-engineer it.
