# Character States

The Active Counter as a state model: each squadron member is ACTIVE, LOST, or RETURNED,
and the count is displayed as `SQUADRON // N ACTIVE`.

Canonical progression <span class="sq-badge canon">CANON</span>: `4 → 3` (Markus lost) `→ 4` (returned) `→ 5`
(finale, unknown contact classified FRIENDLY).

Fuller state design is <span class="sq-badge open">OPEN</span>.
