# HUD Communications

The interface/state language that appears both in prose and in any adaptation. Kept
consistent because it carries emotional weight.

## Established display strings <span class="sq-badge canon">CANON</span>

- `SQUADRON // 4 ACTIVE` — and its changes: `3 ACTIVE`, `4 ACTIVE`, `5 ACTIVE`.
- `UNKNOWN CONTACT` → `FRIENDLY` (the finale classification by [Markus](../characters/markus.md)).

## Established comms behavior <span class="sq-badge provisional">PROVISIONAL</span>

- Loss of **[Relay](../world/relays.md)** connectivity removes [Kristina](../characters/kristina.md)
  from the squadron's comms — a felt absence, not just a status flag.
