# Markus's Loss

The book's low point. `SQUADRON // 4 ACTIVE` → `3 ACTIVE`.

## The canon <span class="sq-badge canon">CANON</span>

Markus is lost. A **substantial [White Ship](../mystery/white_ship.md) encounter** occurs
around the catastrophic loss — and it **does not save him.** This is deliberate: it keeps
the White Ship from becoming an automatic guardian angel. Markus is instead brought home
months later by [Rafa](../characters/rafa.md).
