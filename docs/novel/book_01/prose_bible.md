# Prose Bible

How Book One is written.

## POV <span class="sq-badge provisional">PROVISIONAL</span>
Close third person, **rotating** among leads/core (start with [Greg](../../characters/greg.md)
and [Markus](../../characters/markus.md)). **One POV per scene.** POV changes at chapter/section seams.

## Tense <span class="sq-badge open">OPEN</span>
Past tense assumed unless decided otherwise.

## Tone
Character-driven and grounded; the emotional book lives in the quiet 'sequel' beats
after action, not only in the set pieces. Restraint over spectacle. Themes stay nearly
silent (see [Themes](../../foundation/themes.md)).

## Display language <span class="sq-badge canon">CANON</span>
Interface/state text is a motif: `SQUADRON // N ACTIVE`, `UNKNOWN CONTACT`, `FRIENDLY`.
Render consistently (see [HUD Communications](../../game/hud_comms.md)).

## Hard rules
All entries in [Narrative Rules](../../foundation/narrative_rules.md) apply to prose.
